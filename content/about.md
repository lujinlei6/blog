## 这个站点

VOID 是一个关于前端工程、界面设计与技术决策的中文博客。

名字取自「虚空」——不是故弄玄虚，而是这个站点想坚持的一件事：**在信息过载的环境里，留出一块不被算法和热点填充的空间**。写下来的东西应该经得起半年之后再读一遍。

所以这里没有日更，没有标题党，没有为了 SEO 堆砌的关键词。文章更新频率取决于是否真的有话要说。

## 关于我

我是 Mt342，前端工程师。

日常工作是把复杂的东西变得可用，业余爱好是把可用的东西讲清楚。相信好的工程不是消除复杂度，而是**把复杂度放回它该待的地方**——该在构建期的不要留到运行时，该在服务端的不要塞进客户端，该由类型系统承担的不要靠 code review。

写作对我而言是一种思考方式。很多判断在脑子里是模糊的直觉，只有写下来才发现它站不站得住。所以这里公开发布的内容，大部分是我为了说服自己而写的。

## 技术栈

这个站点本身就是一次技术选型的结果，如果你好奇它是怎么搭起来的：

- **框架** — TanStack Start（v1 正式版），SSR + Nitro
- **路由** — TanStack Router，类型安全的文件路由
- **样式** — Tailwind CSS 4，CSS-first 的 `@theme` 设计令牌
- **内容** — 仓库内的 Markdown 文件，构建时内联
- **排版** — 针对中文长文单独调校，详见《中文网页排版的十条规矩》
- **代码高亮** — Shiki，在服务端渲染成静态 HTML

没有客户端数据层库，没有动画库，没有评论系统。全站只有一个客户端交互组件——滚动揭示动效，约三十行，用原生 `IntersectionObserver` 实现，并且在禁用 JavaScript 时内容依然完整可见。

这不是技术炫耀，而是一个判断：**博客的核心功能是阅读，任何不服务于阅读的东西都是负担。**
